# Candid Captures

Static portfolio site for Abbey Molina, Adelaide photographer. Built by Higgsfield, exported and re-hosted on Vercel for `candidcaptures.com.au` (or chosen domain).

## Stack

- Static single-page site
- Vite-built React bundle (index.js) + Tailwind-compiled CSS (styles.css)
- 11 image assets in `/assets/`
- Zero server dependencies — serves 100% from Vercel's edge

## Deploy

```bash
cd "$HOME/Library/CloudStorage/OneDrive-earthedhv.au/000 unearthed/_CandidCaptures"

# 1. Init git
git init -b main
git config user.email "calebvears@earthedhv.au"
git config user.name "Caleb Vears"
git add -A
git commit -m "Initial import — Candid Captures site exported from Higgsfield"

# 2. Push to GitHub
gh repo create calebvears-earthed/candid-captures --private --source=. --push --remote=origin

# 3. Deploy to Vercel
# Visit https://vercel.com/new → import calebvears-earthed/candid-captures
# Framework preset: Other (static site)
# Root directory: ./
# Build command: (leave blank)
# Output directory: ./ (root)
# Deploy → live at candid-captures.vercel.app in ~60 sec

# 4. Custom domain
# Vercel → Project → Settings → Domains → Add candidcaptures.com.au
# Follow DNS records — typically A record to 76.76.21.21 + CNAME www to cname.vercel-dns.com
```
